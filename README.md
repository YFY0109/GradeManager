# GradeManager · 成绩管理系统

用于学校录入成绩、查询考试排名和统计结果，以及导出成绩表。

## 背景

- 现状：高一月考成绩以 Excel 维护（单点录入、公式自动计算总分/排名、分数序视图、缺考处理）。
- 痛点：多人协作录入易冲突、文件分发导致整表可见（隐私）、修改无审计、跨考试数据难积累。
- 结论：Excel 作为录入前端的习惯可以延续，但数据与计算逻辑迁移到数据库。

## 目录结构

- `app/` — FastAPI 后端
- [`web/`](web/README.md) — Vue 前端与构建说明
- `db/` — PostgreSQL 表结构和迁移脚本
- `scripts/` — 数据导入与运维脚本
- `docs/` — 项目文档

## 数据与开发

- 已导入的成绩以数据库为准，原始 Excel 只读归档。导入步骤见 [数据导入记录](docs/M1-数据导入.md)。
- 后端依赖使用 `uv` 管理。数据库结构、权限和线上部署的变更需先确认。
