## 2. 导出接口

```text
GET /api/exams/{exam_pid}/export.xlsx?kind=full&scope=all|grade|classes
GET /api/exams/{exam_pid}/export.xlsx?kind=grade_rank
GET /api/exams/{exam_pid}/export.xlsx?kind=class_rank&class_pid=...
GET /api/exams/{exam_pid}/export.xlsx?kind=stats
```

- `scope=grade`：仅年级总表
- `scope=classes`：年级总表 + 各班分 Sheet
- `scope=all`（缺省）：按模板 `sheets` 配置（默认两者都导）
- 文件名使用 UTF-8（`filename*=UTF-8''...`），中文正常

## 3. 完整成绩表列结构（默认，对齐参考文件）

```text
班级 | 姓名 | 学号 | 名次 | 语文 | 语文次 | 数学 | 数学次 | ... | 总分 | 平均分
```

- 单行表头
- 每科默认：得分 + 级位次（`{subject}次`）
- 可选开启：班位次（`fields.class_rank`）、每科班位次（`subject_columns.class_rank`），开启后为：
  `班级 | 姓名 | 学号 | 名次 | 班位次 | 语文 | 语文次 | 语文班次 | ...`
- 列顺序固定，配置只控制开关/标签/宽度/数字格式

## 4. 配置 API

```text
GET /api/config/export/full      # 读取完整成绩表模板（缺失项回退默认）
PUT /api/config/export/full      # 更新（管理员；未知字段/非法值 422）
GET /api/config/export/stats     # 统计表模板
PUT /api/config/export/stats
```

- 存储：`app_config` 表，key = `export.full.template` / `export.stats.template`
- 读取时自动与默认值合并（版本升级新增字段不会破坏旧配置）
- 写入校验：Pydantic 严格模式（`extra="forbid"`）

## 5. 口径（与 Excel 逐项对齐）

| 项 | 规则 |
|---|---|
| 总分排名池 | **五科齐全**学生；位次 / 班位次均只在这些学生中排 |
| 单科排名池 | **该科有成绩**的学生（含部分缺考学生）；与 Excel 一致 |
| 三率 | 分母 = 该科有成绩人数；优秀 85% / 及格 60% / 过差 40% |
| 平均分 | 仅五科齐全学生（总分 / 科目数） |
| 缺考 | 分数存 `NULL`；导出时：全科缺考 → 「缺考」，部分缺考 → 「部分缺考」 |
| 缺考学生位次 | **所有位次列**（总分/班/级、单科/班/级）显示三态文字，不显示数字 |
| 缺考学生单科得分 | 有分科目正常显示，缺考科目留空 |
| 并列 | `RANK` 并列同名次、跳号（与 Excel RANK 一致） |
| 排序 | 年级表按级位次；班级表按班内位次；缺考学生排最后（按考号） |

> 本次修正：原 M2 单科排名误用“五科齐全”池，导致单科位次与 Excel 差 1–2 名；已改为“该科有分者”并完成 0 差异校验。
