# M5 Web 客户端（核心闭环 · 已完成部分）

> 2026-11-27 · Vue 3 SPA + Cookie 会话
> 规划见 `docs/M5-客户端规划.md`

## 1. 技术栈

| 项 | 选型 |
|---|---|
| 框架 | Vue 3.5 + TypeScript |
| 构建 | Vite 8 |
| UI | Element Plus 2.14（中文 locale） |
| 图表 | ECharts 6（按需引入 BarChart） |
| 状态 | Pinia 4 |

| HTTP | Axios（`withCredentials`） |
| 位置 | `web/`（源码），构建产物 `web/dist`（不入库） |

## 2. 认证

- 登录：`POST /api/auth/login` 同时返回 token 并设置 **HttpOnly Cookie** `gm_token`（`SameSite=Lax`、HTTPS 下 `Secure`）
- 页面请求自动携带 Cookie；后端 `current_user` 优先 Bearer，其次 Cookie
- 登出：`POST /api/auth/logout` 清除 Cookie
- CSRF：非 GET 请求校验 `Origin/Referer` 与 Host 同源（本地开发放行 localhost）
- 旧 token 策略不变：禁用/改密/权限变更后 `token_version` 使会话立即失效

## 3. 页面（首期）

| 路由 | 页面 | 功能 |
|---|---|---|
| `/login` | 登录 | 账号密码、锁定提示 |
| `/dashboard` | 首页 | 角色/范围概览、考试卡片、快捷入口 |
| `/scores` | 成绩录入 | 考试+班级选择、动态科目列、空值=缺考、差异保存、保存后刷新 |
| `/rankings` | 排名 | 年级/班级切换、总分/单科、前三名高亮、按当前条件导出 |
| `/stats` | 统计 | 年级卡片、科目三率、分数段/科目均分/班级均分图表、班级明细 |
| `/export` | 导出 | 完整成绩表（范围）/ 排名表 / 统计表，Blob 下载 |
| `/profile` | 个人设置 | 账号与范围、修改密码（改后强制重新登录） |

菜单与页面按能力显示：无 `enter_scores` 不显示录入；无 `view_total` 不显示总分选项；科任老师不显示完整成绩表导出。

有 `create_exam` 权限的录入用户可在「成绩录入」点击「新增考试」。填写名称和类型，日期选填；周考需选一个科目，其他类型按既有规则配置科目。创建后保留所选班级，切换到新考试。

## 6. 部署方式（已实施）

- 本地 `cd web && npm run build`
- 打包 dist：`tar -czf gm_web_dist.tar.gz -C web/dist .`
- 上传产物并解压到服务器项目的 `web/dist`，文件属主按部署配置设置。
- **站点由宝塔面板「HTML项目」托管**（根目录 `web/dist`）：
  - 面板「伪静态」配置 SPA 回退与 `/api` 反代
  - 面板 SSL 部署覆盖站点域名的证书，开启强制 HTTPS
  - SSL 续期由 **AllinSSL** 管理（不重复申请）
- 服务器无需 Node（Vue 构建产物是纯静态文件；后端为 Python FastAPI）
- 代码更新：服务器 `git pull` 可能受 GitHub 网络影响，走 Clash 代理：
  `git -c http.proxy=http://127.0.0.1:7890 -c http.version=HTTP/1.1 pull`
- 站点地址使用部署环境配置；示例：`https://grade.example.com`
