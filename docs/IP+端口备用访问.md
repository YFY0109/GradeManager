# IP + 端口备用访问（2026-11-28）

> 本文的域名、IP 和备用端口均为示例，请替换为部署环境的值。

## 1. 入口

```text
http://192.0.2.10:8080/
```

- 协议：HTTP（不经过 HTTPS SNI）
- 示例端口：8080
- 用途：域名未备案或 SNI 被阻断时的临时入口
- 同一套前端与 API：`/` 指向 `web/dist`，`/api/` 反代 `127.0.0.1:8000`

## 2. 宝塔面板配置

在 HTML 项目 `grade.example.com` 的「域名管理」中添加：

```text
192.0.2.10:8080
```

面板自动在站点配置中增加：

```nginx
listen 8080;
server_name grade.example.com 192.0.2.10;
```

并在 HTTP→HTTPS 跳转条件中放行备用端口（否则仍会 301 到 HTTPS）：

```nginx
if ($server_port = 8080) {
    set $isRedcert 1;
}
```

在宝塔「系统 → 系统防火墙」为预期访问来源放行备用端口，例如：

```text
TCP 8080，来源为授权访问网段，策略为放行
```

## 3. 验证

- 服务器本机：访问备用端口的 `/health`，应返回 `{"status":"ok"}`。
- 外网：访问部署环境的备用地址，首页应返回 HTTP 200。
- 登录、`/api/auth/me`、管理页面正常
- 域名 HTTP 仍保持 301 到 HTTPS，不影响原入口
- 如果域名受网络或备案影响，可验证备用入口是否能独立访问。

## 4. 安全注意

- HTTP 为明文传输，登录密码和 Cookie 不加密；仅建议临时使用
- Cookie 会根据请求协议自动设置 `Secure`：HTTP 入口不设置 Secure，HTTPS 入口设置
- 域名恢复后，删除备用绑定并关闭防火墙上的备用端口。
- IP 直连不能替代 ICP 备案；对外长期提供服务仍应完成备案

## 5. 关闭方式

1. 宝塔 → 网站 → 目标站点 → 域名管理 → 删除备用 IP 与端口绑定
2. 宝塔 → 系统 → 系统防火墙 → 删除备用端口的放行规则
3. 重载 Nginx
