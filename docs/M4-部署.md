# M4 部署（已完成）

> 2026-11-27 · 云服务器部署记录。本文的站点域名 `grade.example.com` 和 `/path/to/` 路径均为示例。
> 规划见 `docs/M4-部署规划.md`

## 1. 架构

```text
Internet
   │  HTTPS 443（站点证书）
   ▼
宝塔 Nginx（grade.example.com）
   │  proxy_pass 127.0.0.1:8000
   ▼
uvicorn（systemd: grademanager.service，单 worker，非 root）
   │
   ▼
PostgreSQL 18.6（127.0.0.1:5432）
```

## 2. 服务器变更清单

| 项 | 内容 |
|---|---|
| 运行用户 | `grademanager`（系统用户，无登录 shell 需求） |
| 代码目录 | `/path/to/GradeManager`（公共仓库 clone） |
| Python | uv 0.13.10 + CPython 3.12.16（uv 独立安装，不影响系统 3.11） |
| 虚拟环境 | 项目目录下的 `.venv`（`uv sync --frozen`） |
| 环境变量 | `.env`（600；DSN 本机 5432、随机 JWT secret、时区） |
| 服务 | `/etc/systemd/system/grademanager.service`（`Restart=always`、`enabled`） |
| 站点 | **宝塔面板「HTML项目」**，根目录 `web/dist`；配置由面板生成 |
| 反代/伪静态 | 面板「伪静态」：SPA 回退 + `/api/`、`/health`、`/docs`、`/openapi.json` 反代 `127.0.0.1:8000` |
| 证书 | 在宝塔面板配置站点证书，续期由 AllinSSL 管理 |
| HTTPS | 面板「强制 HTTPS」已开启（HTTP 301） |
| 备份 | 在专用备份目录运行脚本，按 cron 计划保留备份 |
| 日志 | `journalctl -u grademanager`；Nginx 日志可在宝塔站点配置中查看 |

### 站点配置要点（均在宝塔面板维护）

- 网站 → HTML项目 → 目标站点 → 设置
- 伪静态：`try_files $uri $uri/ /index.html`（SPA 回退）+ `/api` 反代
- SSL：部署覆盖站点域名的证书，开启强制 HTTPS
- 前端构建产物由本地 `npm run build` 上传到 `web/dist`，线上不需要 Node

### systemd 关键参数

```ini
User=grademanager
WorkingDirectory=/path/to/GradeManager
ExecStart=/path/to/GradeManager/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 \
          --workers 1 --limit-concurrency 8
Restart=always
```

> 单 worker 和并发限制用于控制内存峰值；按部署环境评估实际并发能力。

## 4. 日常运维

### 服务

```bash
systemctl status grademanager
systemctl restart grademanager
journalctl -u grademanager -n 100 --no-pager
```

### 更新发布

```bash
cd /path/to/GradeManager
git pull
su - grademanager -c "cd /path/to/GradeManager && uv sync --frozen"
# 如有新增迁移：
# /www/server/pgsql/bin/psql -h 127.0.0.1 -U grademanager -d grademanager -f db/00X_xxx.sql
systemctl restart grademanager
curl -s http://127.0.0.1:8000/health
```

### 备份与恢复

```bash
# 手动备份
/path/to/backups/grademanager/backup.sh

# 恢复（示例：恢复到临时库校验）
su - postgres -c "/www/server/pgsql/bin/createdb -h /tmp gm_restore_test"
su - postgres -c "/www/server/pgsql/bin/pg_restore -h /tmp -d gm_restore_test /path/to/backups/grademanager/example.dump"
# 校验后删除临时库
```

### 站点（宝塔面板）

- 网站 → HTML项目 → 目标站点 → 设置
- 伪静态、SSL、强制 HTTPS 均在面板维护；修改后面板自动重载
- 排查日志（只读）：查看站点配置指定的 Nginx 错误日志。
- 通过宝塔面板更新站点配置，直接编辑生成文件会被面板覆盖。

## 5. 回滚

- 代码：`git checkout <上一版本>` → `systemctl restart grademanager`
- 配置：`.env`、systemd 文件有备份；站点配置可在宝塔面板「配置文件」查看/回滚
- 数据库：迁移均为幂等 DDL；如需回滚用备份恢复
- 停用站点：在宝塔面板禁用相应站点。

## 6. 已知边界与后续

| 项 | 说明 |
