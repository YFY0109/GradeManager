# 学情总览与学生成绩复刻方案

> 2026-11-27 · 依据 `docs/智学网报告页调研.md`，先方案后实施
> 目标：在现有 Vue 3 + Element Plus 客户端中复刻「学情总览」与「学生成绩」两块

## 1. 复刻范围

### 本期（P0 + P1）

1. **学情总览**（班级/年级可切换）：
   - 指标卡：实考/缺考、均分、最高/最低、优秀率/良好率/合格率/低分率
   - 学科成绩对比表（14 列）
   - 学业等级分布（柱状图）
   - 成绩分段对比（折线图 + 智能评语）
   - 优劣势学科对比（雷达图 + 优势/劣势列表）
2. **学生成绩**：
   - 表格：序号/考号/姓名/班级/总分/各科/名次
   - 缺考标记（缺考，不计排名）
   - 指标筛选（显示哪些科目列）
   - 导出（复用现有完整表/排名导出）
3. **对比考试**：两场考试分数/进退步对比
4. **班级成绩对比**：多班均分/三率横向对比
5. **用户管理**（与报告同级，仅 admin）：
   - 用户列表（用户名/姓名/角色/状态/班级/科目/最后登录）
   - 新建/编辑/禁用/重置密码/授权范围
   - 复用现有 `/api/users` 接口
6. **配置管理**（与报告同级，仅 admin）：
   - 统计口径配置（优秀/良好/及格/过差阈值、等级模式：按比例/按排名）
   - 导出模板配置（完整表/统计表）
   - 复用/扩展现有 config API

### 后续（P2）

- 临界生统计（临界分 ± 浮动分）
- 优秀生/学困生统计（前 N/后 N）
- 进线分析（单科上线/双上线/贡献率/命中率，需分数线配置）

> 逐题/知识点分析不做（智学网在线阅卷数据，我们只有分数）。

## 2. 页面结构对照

[考试] [班级] [指标筛选] [对比考试（P1）]

- 按总分/名次排序
- 缺考显示“缺考，不计排名”
- 列可配置（指标筛选）

## 3. 指标与数据缺口

| 智学网指标 | 现状 | 缺口/方案 |
|---|---|---|
| 实考/缺考人数 | 有（NULL 统计） | 补“缺考人数”字段 |
| 满分 | 有 | 无 |
| 最高/最低/平均 | 有（stats） | **平均分改为该科有分者**（与 Excel 公式一致） |
| 学科均分排名 | 无 | 新增：年级内各科均分排名 |
| 优秀率（85%） | 有 | 无 |
| 良好率（70%） | 无 | **新增 70%**（与期中 Excel 一致） |
| 合格率（60%） | 有（及格率） | 改名/口径统一 |
| 低分率（30%） | 现有过差率 40% | **修正为 30%**（与 Excel 公式一致） |
| 超均率 | 无 | 新增：学科均分 / 年级均分 |
| 标准差 | 无 | 新增 `stddev`（总体标准差） |
| 等级分布（A-E） | 无 | 新增：按比例/按排名可配置 |
| 总分分段 | 有 | 保留 |
| 单科分段 | 无 | 新增 |
| 优劣势学科（z 分数） | 无 | 新增：z = (班级均分-年级均分)/标准差 |
| 对比考试 | 无 | 本期新增（P1） |
| 班级横向对比 | 无 | 本期新增（P1） |
| 学生名次 | 有（rankings） | 学生成绩接口直接返回 grade_rank/class_rank |

## 4. 后端改造

### 4.1 新增/扩展接口

```text
GET /api/exams/{exam_pid}/overview?class_pid=&subject_pid=
  → 学情总览聚合（指标、学科对比、等级分布、分段、优劣势）

GET /api/exams/{exam_pid}/students?class_public_id=&with_rank=true
  → 学生成绩列表（含总分、各科、年级/班级名次、缺考状态）

GET /api/exams/{exam_pid}/compare?with_exam_pid=&class_pid=   （P1）
```

### 4.2 统计口径

- 均分/最高/最低/标准差：该科**有成绩**学生（与 Excel `AVERAGE(该科)` 一致）
- 总分平均：五科齐全学生
- 三率：优秀 85% / 良好 70% / 及格 60% / 过差 30%；分母 = 该科有成绩人数
- 超均率：学科均分 / 年级（或范围）均分
- 学科均分排名：范围内各科均分横向排名（1 = 最高）
- 等级分布：配置切换「按比例」（总分百分比）或「按排名」（名次百分比），默认按比例
- 单科分段：按满分百分比 10 段（可配置）
- 优劣势：z 分数（总体标准差），正为优势、负为劣势

### 4.3 配置（app_config）

```jsonc
{
  "stats.thresholds": { "excellent": 0.85, "good": 0.70, "pass": 0.60, "poor": 0.40 },
  "stats.grade_levels": [
    { "name": "A", "min_ratio": 0.85 },
    { "name": "B", "min_ratio": 0.70 },
    { "name": "C", "min_ratio": 0.60 },
    { "name": "D", "min_ratio": 0.40 },
    { "name": "E", "min_ratio": 0 }
  ]
}
```

## 8. 验收标准

- 指标与现有 Excel/API 抽查一致（均分、最高/最低、三率）
- 标准差/超均率/排名计算正确（抽样手算核对）
- 等级分布人数合计 = 实考人数
- 分段人数合计 = 实考人数
- 学生成绩按名次排序、缺考标记正确
- 权限：teacher 仅所授科；head 仅本班；viewer 只读
- 页面首屏 < 2s，图表渲染正常
- 移动端可查看

## 9. 风险与边界

| 风险 | 对策 |
|---|---|
| 口径不一致（良好率/低分率） | 先与 Excel 总评核对，配置化阈值 |
| 标准差分母（总体/样本） | 明确用总体标准差（Excel STDEV.P 口径） |
| 等级区间固定分数 vs 比例 | 默认比例，支持配置固定分数 |
| 多班级学生数据 | 聚合查询 + 前端分页/虚拟滚动 |
| 图表过多影响性能 | 按需渲染、懒加载 |

## 11. 完成记录（2026-11-27）

### 信息架构（用户调整后）

顶层菜单：

```text
首页 | 测验报告 | 成绩录入 | 导出中心 | 用户管理 | 配置管理 | 个人设置
```

- **测验报告**：考试列表 + 筛选（类型/名称），点击进入该次考试的报告
- **报告页**：顶部「年级报告 / 班级报告」切换（按权限显示），两种报告均包含 `学情总览` / `学生成绩` 两个 tab
- **学生成绩**：成绩明细表中，每个分数后紧跟相应名次。年级报告显示年排，班级报告显示年排和班排，各列按账号权限显示。
- 移除顶层的「学生成绩」「排名查询」「学情总览」
- 旧链接 `/stats`、`/student-scores`、`/rankings` 重定向到 `/reports`

### 后端

- 统计口径修正：优秀 85% / 良好 70% / 及格 60% / 过差 30%；单科均分按该科有分者
- 新增 `GET /api/exams/{exam_pid}/overview?class_pid=`：指标、学科对比、等级分布、分段、优劣势（z 分数）、班级对比
- 新增 `GET/PUT /api/config/stats`：统计阈值与等级模式（存 `app_config`）
- 权限：teacher 仅所授科；非全年级账号必须指定班级

### 前端

- 学情总览（StatsView 重写）：指标卡、14 列学科对比、等级柱状图、分段折线图 + 智能评语、优劣势雷达、班级对比
- 年级报告的班级对比按总分及各科均分标出班级名次（同均分并列，无成绩不排名）；前端可按班级、人数、齐全人数或均分升降序排列。
- 学生成绩（StudentScoresView）：表格、缺考/部分缺考、年级/班内名次、指标筛选、对比考试、导出
- 学生成绩表支持按姓名或考号搜索，搜索后按匹配名单分页，原名次不变。默认 50 条/页，点击名次列表头可排序
- 对比考试按共同科目展示分数、得分率差（百分点）及有权限查看的名次变化。满分不同时省略原始分差，合计的得分率为各科得分率的平均值；科目和满分均一致时对比总分及其名次。
- 用户管理（UsersView）：列表、新建/编辑、禁用/启用、重置密码、班级/科目授权
- 配置管理（ConfigView）：统计阈值、等级模式、等级列表、分段数、导出模板 JSON
- 侧边栏：学生成绩、用户管理、配置管理（与报告同级）

### 验收

- 只读账号：仅班级视角，菜单无录入/管理。
- 6 班学生成绩：缺考/部分缺考标记、名次留空正确
- 配置保存/恢复通过（segment_count 10→12→10）
