# 学情指标扩展方案

> 目标：在现有「学情总览」基础上，补齐智学网的临界生、优秀生/学困生、进线分析，
> 并增加得分率、中位数、变异系数、名次段、学科均衡度等可基于现有成绩直接计算的指标。
> 不引入逐题/知识点分析（无阅卷明细数据）。

## 1. 范围

### 1.1 本次实现

| 分类 | 指标 |
|---|---|
| 学科统计 | 得分率、中位数、极差、变异系数、满分人数 |
| 分布 | 单科等级分布、单科分段对比 |
| 名单 | 各科缺考名单 |
| 班级分析 | 优秀生/学困生（前 N/后 N）、名次段人数、分数段按班分布 |
| 均衡性 | 学科均衡度（偏科指数）、班级离散度（标准差/变异系数） |
| 分数线 | 临界生对比、进线分析（总分上线/单科上线/双上线/贡献率/命中率） |
| 排名 | 同分人数 |
| 对比考试 | 进步/退步汇总 |

### 1.2 不做

- 逐题、知识点、试卷讲评、作文分析（无数据）。
- 「未扫」状态（无阅卷状态字段）。
- 联考/跨校排名（无外部数据）。

## 2. 口径定义

### 2.1 学科统计

- **得分率** = 均分 ÷ 该科满分。
- **中位数**：有效成绩排序后取中；偶数个取中间两数平均。
- **极差** = 最高分 − 最低分。
- **变异系数 CV** = 标准差 ÷ 均分；均分为 0 时为空。
- **满分人数** = 成绩等于该科满分的人数。
- 所有统计只计有效成绩（`score IS NOT NULL`），缺考不参与。

### 2.2 单科等级/分段

- 等级：沿用统计配置的 `grade_mode` 与 `ratio_levels` / `rank_levels`，
  分母为该科有效人数，满分取该科 `full_score`。
- 分段：沿用 `segment_count`，按该科满分比例等分。
- 总分等级/分段保持现状。

### 2.3 优秀生 / 学困生

- 排名池：所有考试科目均有有效成绩的学生（齐全学生），总分降序，`RANK` 并列。
- 优秀生：年级总分名次 ≤ N；学困生：年级总分名次 > 最大名次 − N。
- N 取统计配置 `top_n`，默认 10。
- 按班输出人数与占比（占比 = 人数 ÷ 该班齐全人数）。
- 依赖排名能力：年级报告需 `can_rank_grade`，班级报告需 `can_rank_class`。

### 2.4 名次段人数

- 分段点：前 10 / 50 / 100 / 200 名（固定）。
- 按班统计 `grade_rank <= 分段点` 的人数与占比（占比 = 人数 ÷ 该班齐全人数）。
- 依赖排名能力，规则同上。

### 2.5 分数段按班

- 复用总分分段边界（`segment_count`）。
- 每班各段人数与占比（占比 = 人数 ÷ 该班齐全人数）。
- 不需要排名能力。

### 2.6 学科均衡度

- 对每个齐全学生：计算各可见科目的得分率，求总体标准差与极差。
- 按班汇总平均偏科指数（平均标准差、平均极差）。
- 仅使用当前用户可见科目；可见科目少于 2 科时不计算。
- 班级报告只返回当前班；不返回学生姓名。

### 2.7 班级离散度

- 各班各科：有效人数、标准差、变异系数。
- 年级报告提供班级 × 科目的 CV 对比；班级报告提供本班各科标准差/CV。
- 仅可见科目。

### 2.8 临界生

配置：

```json
{
  "top_n": 10,
  "critical_margin": 20,
  "subject_margin": 0.05,
  "cutoff_lines": [
    { "name": "本科线", "total": 500, "subject_ratio": 0.6 }
  ]
}
```

- 总分临界生：总分在 `[total − critical_margin, total + critical_margin]` 内的齐全学生。
- 单科临界生：单科得分率在 `[subject_ratio − subject_margin, subject_ratio + subject_margin]`
  内的有效成绩。
- 按班统计人数与占比；班级报告额外返回本班临界生名单。
- 未配置分数线时，接口返回空列表，前端提示到配置页设置。

### 2.9 进线分析

对每条分数线：

- **总分上线**：总分 ≥ `total`。
- **单科上线**：单科成绩 ≥ 该科满分 × `subject_ratio`（配置了 `subject_ratio` 时）。
- **双上线**：总分上线且指定科目单科上线；对每个可见科目分别计算。
- **贡献率**：该班上线人数 ÷ 年级上线人数。
- **命中率**：该班上线人数 ÷ 该班齐全人数。
- 按班输出；班级报告只返回当前班。

### 2.10 同分人数

- 排名 SQL 增加 `COUNT(*) OVER (PARTITION BY value)`。
- 前端在名次后以 `title` 提示「并列 N 人」，不改变列宽。

### 2.11 进步/退步汇总

- 基于对比考试页已有数据，在前端计算：
  - 可比人数（本次与对比均有成绩）
  - 进步 / 退步 / 持平人数
  - 平均分差（满分相同）或平均得分率差（满分不同）
  - 最大进步 / 最大退步学生

## 3. 接口设计

### 3.1 扩展 `GET /api/exams/{exam_pid}/overview`

在现有响应上新增（向后兼容）：

```text
subjects[] / total:
  score_rate, median, range, cv, full_count

subject_levels:  { [subject_name]: GradeLevelStat[] }
subject_segments:{ [subject_name]: SegmentStat[] }
absentees: [
  { subject, students: [{ student_public_id, student_no, name, class }] }
]

analytics: {
  top_bottom: { n, classes: [{ class, top_count, top_ratio, bottom_count, bottom_ratio }] },
  rank_bands: { bands: [10,50,100,200], classes: [{ class, counts, ratios }] },
  class_segments: { segments: [{label,min,max}], classes: [{ class, counts, ratios }] },
  balance: { classes: [{ class, avg_std, avg_range, students }] } | null,
  dispersion: {
    subjects: [name],
    classes: [{ class, values: { [subject]: { stddev, cv } } }]
  },
  critical: {
    configured: boolean,
    lines: [{ name, total, subject_ratio, margin, subject_margin }],
    total: [{ line, classes: [{ class, count, ratio, students? }] }],
    subjects: [{ line, subject, classes: [{ class, count, ratio }] }]
  },
  cutoffs: {
    configured: boolean,
    lines: [{
      name, total, subject_ratio,
      classes: [{
        class, eligible, total_online, total_rate, contribution_rate,
        subjects: { [subject]: { online, rate } },
        double: { [subject]: { online, rate } }
      }]
    }]
  }
}
```

裁剪规则：

- `view_total` 关闭：不返回总分字段与总分相关分析。
- `view_subject` 关闭：不返回单科等级/分段、离散度、单科临界/进线。
- 科目范围受限：只返回授权科目。
- `can_rank_grade` / `can_rank_class` 关闭：`top_bottom`、`rank_bands` 置空。
- 班级报告：`analytics` 只返回当前班；`absentees` 只当前班。

### 3.2 扩展排名接口

`GET /api/exams/{exam_pid}/rankings/...` 每行新增 `tied_count`。

### 3.3 扩展统计配置

`GET/PUT /api/config/stats` 新增：

```text
top_n: int = 10
critical_margin: float = 20
subject_margin: float = 0.05
cutoff_lines: [{ name, total, subject_ratio }]
```

存储仍为 `app_config` 的 `stats.config` JSONB，无数据库迁移。

## 4. 前端改动

### 4.1 学情总览

- 指标卡：参考人数、缺考、总分平均、最高、最低、中位数、标准差、变异系数。
- 学科成绩对比表新增：得分率、中位数、极差、变异系数、满分人数。
- 等级分布、分段对比增加科目切换（总分 + 各科）。
- 缺考人数可点击查看名单。
- 新增 `AdvancedStatsPanel`：
  - 优秀生/学困生
  - 名次段人数
  - 分数段按班（堆叠柱状图）
  - 学科均衡度（班级报告）
  - 班级离散度
  - 临界生对比
  - 进线分析

### 4.2 配置管理

- 优秀生/学困生人数 N。
- 临界生总分浮动分、单科浮动比例。
- 分数线列表编辑（名称、总分线、单科得分率）。

### 4.3 学生成绩

- 名次后 `title` 提示并列人数。

### 4.4 对比考试

- 顶部汇总：可比人数、进步/退步/持平、平均分差、最大进步/退步。

## 5. 权限

- 所有新增统计沿用 `view_stats` 入口权限。
- 总分分析需要 `view_total`；单科分析需要 `view_subject`。
- 优秀生/学困生、名次段需要对应排名能力。
- 分数线配置需要 `manage_config`。
- 班级范围沿用 `assert_class_allowed` / `scope` 裁剪。

## 6. 兼容性与性能

- 所有新字段有默认值，旧配置无需迁移。
- 分析在现有 overview 内存数据上计算，不新增数据库表；
  476 人 × 9 科规模下开销可忽略。
- 前端新表格均使用 Element Plus，不引入新依赖。

## 7. 验收

- `npm run build` 类型检查与构建通过。
- `python -m compileall app` 通过。
- 年级报告、班级报告均能加载新增模块。
- 无分数线配置时展示引导提示，不报错。
- 只读/科任老师账号看不到越权科目与总分分析。
