# 期中考试导入记录（2026-11-28）

## 1. 数据源

- 原始 Excel 保存在受控环境；以 `rank` 工作表为导入依据，与打印版和年级分析表交叉核对。
- 考试类型为 `midterm`。考试持续多日时，系统日期填写开始日。
- 科目与满分：

| 科目 | 满分 |
|---|---:|
| 语文 / 数学 / 英语 | 150 |
| 物理 / 化学 / 生物 / 政治 / 历史 / 地理 | 100 |
| **总分** | **1050** |

## 2. 校验结果

- Excel 中的 **0 分表示缺考**；导入数据库时转为 `NULL`，不按 0 分计入统计。
- 非零分数逐格核对；原表的总分/平均分（按含 0 求和）和全科齐全学生的名次一致。
- 系统统计按有效成绩计算，因此各科参考人数、平均分等与 Excel 统计表的“含 0”口径不同，这是预期差异。
- 有效名单与成绩记录数按考试科目数核对一致，非零分数均在各科满分范围内。

## 3. 名单差异与处理

| 情况 | 处理 |
|---|---|
| 导入名单出现考号冲突或姓名写法不一致 | 核对原始名单，确认对应学生后修正映射和姓名 |
| 原表有参考记录，数据库未建档 | 确认学籍和班级后新增在册学生 |
| 数据库有在册记录，原表无本次参考记录 | 不导入本次成绩，保留原在册状态 |
| 其他工作表出现全零占位，但 `rank` 和统计均无参考记录 | 视为未参考；有效参考记录中的 0 分同样按缺考处理 |
| 任意单科为 0 | 该科成绩写为 `NULL`（缺考），总分排名要求全部科目有效 |
| 不同工作表对同分给出不同名次 | 以 `rank` 工作表的并列名次规则为准 |

## 4. 导入结果

- 期中考试已按草稿导入；476 名学生均有本次成绩行，其中 8 人存在缺考科目。
- 全科齐全学生 468 人，总分平均 641.1624，总分满分 1050；历史月考数据不变。
- 导入后的数据库备份保存在受控环境。

导入其他期中考试时，运行 `uv run python scripts/import_midterm.py` 并传入 Excel 路径，使用 `--exam-name` 和 `--exam-date` 指定本次考试。学生须已在 PostgreSQL 名册中；脚本核对考号、姓名和班级后再导入成绩。

如果原表考号确有错误，核实后可通过 `--number-fixes` 提供私有 JSON 文件。键是 `rank` 工作表中的 Excel 行号，值是正确考号，均写为字符串，例如 `{"12": "DEMO001"}`。将实际更正文件放在 `local/`，不要提交到 Git。

## 5. 考试名单机制

- 导入考试以本次 `scores` 成绩行确定名单；没有本次成绩行的学生不出现在本次报告。
- 新建考试时，为全体在册学生预生成 `NULL` 成绩行，形成本次考试名单。
- 未参考不会修改学生在册状态，也不影响历史考试。学籍变更须另行核实。
