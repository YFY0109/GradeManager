# M1 数据导入报告

> 2026-11-27 · 第一次月考数据导入完成

## 1. 数据源

- 文件：校方提供的原始月考 Excel（受控保存，只读）
- 考试：月考
- 科目：语文、数学、英语（满分 150）、物理、化学（满分 100）

## 2. 数据模型（PostgreSQL 18.6 · grademanager 库）

| 表 | 说明 |
|---|---|
| classes | 班级 |
| students | 学生（考号唯一、姓名、班级） |
| subjects | 科目与满分 |
| exams | 考试 |
| exam_subjects | 考试科目与满分 |
| scores | 成绩（NULL = 缺考；唯一约束：考试×学生×科目） |
| import_batches | 导入批次 |
| audit_logs | 审计日志 |

**原则**：只存原始数据；总分、位次、平均分、三率全部由查询派生。

## 3. 导入与校验

脚本：

```bash
uv sync
uv run python scripts/db_exec.py db/schema.sql
uv run python scripts/import_exam.py
```

校验结果（2026-11-27）：

| 检查项 | 结果 |
|---|---|
| 学生数（Excel vs DB） | 一致 ✅ |
| 逐人校验（姓名/总分/班位次/级位次） | **0 差异** ✅ |
| 班级/年级平均分（六项） | **0 差异** ✅ |
| 报告 | `reports/import_report_<时间戳>.json`（本地保存） |

## 4. 缺考与排名口径（已固化）

- 成绩缺失 = `NULL`（不存 0）
- **任意一科缺考 → 该生不进入排名池**（班位次/级位次均为空），不占用名次、不影响他人
- 平均分/统计仅使用"五科齐全"的学生（与 Excel 现行公式一致）
- 并列规则：`RANK()` 并列同名次、跳号（与 Excel RANK 一致）
