# 学科管理

> 2026-11-27 完成。入口：**配置管理 → 学科管理**（需要 `manage_config` 权限）。

## 1. 功能

| 操作 | 说明 |
|---|---|
| 新增学科 | 名称、默认满分、排序；名称不可重复 |
| 编辑学科 | 修改名称、默认满分、排序 |
| 删除学科 | 仅允许删除无任何引用的自定义学科 |
| 引用统计 | 展示每个科目的考试配置数、成绩记录数、用户授权数 |

字段对应 `subjects` 表：

- `name`：科目名称（唯一）
- `full_score`：默认满分，仅用于**新建考试**时写入 `exam_subjects.full_score`
- `sort_order`：排序，数字越小越靠前

## 2. 规则与边界

- **月考固定五科**：语文、数学、英语、物理、化学。这五科带「月考」标记：
  - 不可改名（避免新建月考时按名称匹配失败）
  - 不可删除
  - 默认满分与排序仍可修改
- 自定义科目（如生物、政治、历史、地理）可新增/改名/删除。
- 删除保护：只要存在考试配置、成绩记录或用户授权，就禁止删除，并返回各项引用数量。
- 修改默认满分**不影响历史考试**：统计、排名、导出统一使用 `exam_subjects.full_score` 快照（本次同步修正了 overview / rankings 中误用 `subjects.full_score` 的查询）。
- 新增科目后：
  - 期中/期末创建考试会自动包含全部科目；
  - 月考仍固定五科；
  - 成绩录入、导出中心的科目列按该考试的 `exam_subjects` 快照加载，旧考试不会凭空多出新科目列；
  - 需要给科任老师授权时，在用户管理的「科目范围」中选择。

## 3. API

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/subjects/manage` | `manage_config` | 全部科目 + 引用计数 |
| POST | `/api/subjects` | `manage_config` | 新增学科 |
| PATCH | `/api/subjects/{public_id}` | `manage_config` | 编辑学科 |
| DELETE | `/api/subjects/{public_id}` | `manage_config` | 删除学科（带引用保护） |
| GET | `/api/subjects` | 登录 + 数据范围 | 原有接口，按用户科目范围返回 |

审计动作：`subject.create` / `subject.update` / `subject.delete`。
