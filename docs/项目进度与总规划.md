## 二、已完成部分细节

### 数据

- 数据源（只读）：校方提供的原始 Excel，仅在受控环境保存。
- 数据库 `grademanager`：classes / students / subjects / exams / exam_subjects / scores / import_batches / audit_logs / users / app_config
- 月考的 `exam_type` 为 `monthly`；实际考试标识从考试列表获取。
- 成绩规则：缺考 = NULL；**总分排名池仅五科齐全**；**单科排名池为该科有成绩者**（含部分缺考，与 Excel 一致）；均分仅五科齐全；三率按该科有分人数；优秀 85% / 及格 60% / 过差 40%；缺考学生导出时位次显示三态文字
- 主键：内部自增 id + 对外 public_id（UUID）；API 一律使用 public_id
- exam_type 枚举：weekly（周考/大练考·单科）/ monthly（月考·5科）/ midterm / final（全科）

### 后端 API（M2）

- 启动：`uv run uvicorn app.main:app --host 127.0.0.1 --port 8000`
- 认证：`POST /api/auth/login` → JWT；账号由管理员创建（初始 `admin`）
- 排名接口（已拆分）：
  - `/api/exams/{exam_pid}/rankings/total`
  - `/api/exams/{exam_pid}/rankings/subjects/{subject_pid}`
  - `/api/exams/{exam_pid}/rankings/classes/{class_pid}/total`
  - `/api/exams/{exam_pid}/rankings/classes/{class_pid}/subjects/{subject_pid}`
- 统计：不四舍五入，返回完整数值
- 导出：`kind=full | grade_rank | class_rank | stats`；`kind=full&scope=grade|classes|all`（模板/样式配置见 `docs/导出阶段.md`）
- 配置 API：`GET/PUT /api/config/export/full|stats`（写操作仅管理员）
- 错误码：400/401/403/404 已在 OpenAPI 声明

### 权限与审计（M3）

- 角色：`admin` / `grade_leader` / `head_teacher` / `teacher` / `viewer`
- 范围：`user_classes` × `user_subjects`；接口层强制过滤（越权 403）
- 登录：连续 5 次失败锁 15 分钟；`token_version` 使禁用/改密后旧 token 立即失效
- 审计：成绩变更（旧值/新值）、考试创建、用户变更、登录、导出；`GET /api/audit-logs`
- 用户管理：`GET/POST/PATCH/DELETE /api/users`（`manage_users` 能力）
- 详细验收：`docs/M3-权限与审计.md`

### 线上部署（M4）

- 站点地址由部署环境配置（Swagger：`/docs`）。
- 运行：systemd `grademanager.service`（uvicorn 127.0.0.1:8000，单 worker，非 root）
- Python：uv + 独立 3.12；代码目录由部署环境配置。
- 站点：宝塔面板「HTML项目」托管（伪静态 SPA 回退 + `/api` 反代）；强制 HTTPS
- SSL：使用已有泛域名证书，续期由 **AllinSSL** 管理（不重复申请）
- 备份：cron 定期执行，备份位置和保留策略由部署环境配置。
- 运维/回滚：`docs/M4-部署.md`

### Web 客户端（M5 核心闭环）

- 技术栈：Vue 3.5 + TS + Element Plus + ECharts + Vite 8 + Pinia + Vue Router
- 认证：HttpOnly Cookie（`gm_token`）+ Bearer 兼容 + Origin CSRF 校验
- 页面：登录 / 首页 / 成绩录入 / 排名 / 统计 / 导出 / 个人设置
- 部署：本地 `npm run build` → 上传 `web/dist` → Nginx 静态 + `/api` 反代
- 源码：`web/`；说明：`docs/M5-客户端.md`

### 基础设施

- 云服务器通过宝塔面板管理，应用使用独立的 `grademanager` 数据库与角色。
- PostgreSQL 升级备份与部署记录保存在受控环境。
- 常驻后台：SSH 隧道（15432）+ uvicorn（8000）；重启电脑后需重新启动

## 三、导出专门阶段（已完成 · 2026-11-27）

**目标**：完整成绩表导出 + 样式打磨 + 模板配置入库

**交付**
- `kind=full&scope=grade`：单张全年级表；`scope=classes`：年级总表 + 各班分表；默认按配置
- 列结构默认对齐参考文件：班级/姓名/学号/名次/各科（得分+级位次）/总分/平均分；可选开启班位次
- 样式：宋体 12、细边框、居中、冻结首行、打印标题行、A4 缩放一页宽；统计表仿宋 11 + 标题
- 配置 API：`GET/PUT /api/config/export/full|stats`，存 `app_config`，Pydantic 严格校验，缺省回退
- 修复：班级排名名次（原为年级名次）；单科排名池改为“该科有成绩者”（与 Excel 一致）

**验收**
- 逐人校对总分、各科得分、年级及班级位次，与 Excel 一致。
- 完整表、单表、排名和统计导出均通过验证。
- 配置修改立即生效；非法配置 422

详细说明见 `docs/导出阶段.md`。

**参考样例（用户指定）**
学校提供的导出样式，参考文件仅在受控环境保留。

## 五、常用命令与路径

```powershell
# 加载 uv
. "$HOME\.x-cmd.root\local\data\pwsh\_index.ps1"

# 依赖同步
uv sync

# 执行 SQL
uv run python scripts/db_exec.py db/schema.sql

# 导入第一次月考（幂等）
uv run python scripts/import_exam.py

# 启动 API
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000

# SSH 隧道（替换示例密钥路径、账号和服务器地址）
ssh -i "$HOME/.ssh/example_key" -N -L 15432:127.0.0.1:5432 deploy@192.0.2.10
```

### 线上（服务器）

以下路径为示例，请替换为部署目录。

```bash
systemctl status grademanager
systemctl restart grademanager
journalctl -u grademanager -n 100 --no-pager
cd /path/to/GradeManager && git pull
su - grademanager -c "cd /path/to/GradeManager && uv sync --frozen"
/path/to/backups/grademanager/backup.sh
```
