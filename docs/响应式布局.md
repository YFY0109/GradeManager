# 响应式布局（2026-11-28）

## 1. 断点

| 宽度 | 行为 |
|---|---|
| ≥ 900px | 侧边栏默认展开（220px） |
| < 900px | 侧边栏自动折叠为 64px（图标菜单），窗口缩放时实时响应 |
| ≤ 768px | 页面头部纵向排列；统计卡片 2 列；表单标签上置 |
| ≤ 640px | 分页器换行；表格分页/每页条数左对齐；头部用户名省略 |

## 2. 主要修复

- **统计卡片错位**：`el-row` 同时套用了全局 `.stat-grid` 的 CSS Grid，与 `el-col` 的百分比宽度冲突，卡片被压到 ~100px 并出现横向滚动条。移除该 class，恢复 `el-row/el-col` 栅格。
- **报告页头部**：`report-header`、`report-scope` 允许换行；窄屏下范围切换与班级选择占满整行。
- **侧边栏**：增加 resize 监听，窗口变窄时自动折叠；`el-main` 增加 `min-width: 0`，避免内容把布局撑破。
- **表格分页**：`TablePager` 允许换行，窄屏下分页器换行显示。
- **弹窗/抽屉**：角色、用户、学科弹窗宽度改为 `min(原宽度, 92vw)`；角色抽屉 `min(1000px, 96vw)`。
- **表单**：窄屏下标签改为顶部对齐，避免 140px 标签挤压输入框。
- **全局**：`page-header` 允许换行；窄屏下按钮组占满行宽。

## 3. 验收

浏览器视口 1920 / 1024 / 480 宽度实测：

- 统计卡片：1920 四列各约 390px；480 两列各约 181px，无卡片内横向滚动条。
- 页面无横向溢出（`documentElement.scrollWidth == clientWidth`）。
- 480px：侧边栏 64px、报告页头部纵向排列、统计表在卡片内横向滚动。
- 角色抽屉 461px、编辑弹窗 442px（480px 视口），无溢出。
